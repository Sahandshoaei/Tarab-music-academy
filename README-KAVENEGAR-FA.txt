راهنمای اجرای نسخه نهایی با کاوه‌نگار

این نسخه از REST API کاوه‌نگار با fetch داخلی Node.js استفاده می‌کند؛ نصب پکیج npm اختصاصی Kavenegar لازم نیست و API Key در .env قرار نمی‌گیرد.

تنظیمات
- SchoolSettings.smsProvider = kavenegar
- SchoolSettings.smsApiKey = کلید API کاوه‌نگار (فقط در دیتابیس، سمت سرور)
- SchoolSettings.smsSenderLine = خطی که کاوه‌نگار برای ارسال API به مقصد موردنظر مجاز کرده است.
  اگر خالی بماند، پارامتر sender ارسال نمی‌شود و خط پیش‌فرض حساب کاوه‌نگار استفاده می‌شود؛ فقط وقتی این خط پیش‌فرض در حساب فعال/مجاز است از این حالت استفاده کنید.
- SchoolSettings.smsDefaultPhoneTarget = STUDENT یا GUARDIAN

خطای «ارسال‌کننده نامعتبر است»
خط فرستنده را با شماره مقصد (مثلاً شماره موبایل هنرجو) اشتباه نگیرید. مقدار smsSenderLine باید خط ارسال مجاز حساب کاوه‌نگار باشد. اگر خط فعلی رد می‌شود، یک بار آن را با خط مجاز جایگزین کنید؛ در صورت تأیید کاوه‌نگار می‌توانید مقدار را خالی بگذارید تا خط پیش‌فرض حساب استفاده شود. تا اصلاح خط، ارسال مجدد نزنید.

اجرای محلی
1. ZIP را در پوشه‌ای استخراج کنید.
2. فایل .env شخصی پروژه فعلی را خودتان به پوشه جدید کپی کنید؛ فایل .env عمداً از ZIP حذف شده است تا اطلاعات اتصال دیتابیس/رمزها منتشر نشود.
3. اگر وابستگی‌های پروژه در این پوشه نصب نیستند، اجرا کنید: pnpm install. این نصب برای Next/Prisma پروژه است، نه SDK کاوه‌نگار.
4. اجرا کنید: pnpm typecheck
5. سپس: pnpm dev
6. فقط یک پیام به شماره‌ای که کنترلش دست خودتان است ارسال کنید. ارسال گروهی را تا مشاهده نتیجه انجام ندهید.

تأیید اتصال
- در SmsMessage.providerRef باید شناسه واقعی پیام کاوه‌نگار ثبت شود، نه مقدار mock-...
- خطاهای سرویس در SmsMessage.errorMessage نمایش داده می‌شوند.
- برای پیام‌های قدیمی Mock، وضعیت Delivered واقعی نبوده است؛ با همگام‌سازی در این نسخه به FAILED اصلاح می‌شود.

این نسخه migration جدیدی ندارد؛ فیلدهای SMS از قبل در SchoolSettings و دیتابیس پروژه تعریف شده‌اند. کلید API را در چت یا اسکرین‌شات نفرستید.
