## روش کار (قرارداد منتور و توسعه‌دهنده)

هر تسک در این پروژه با این چرخه جلو می‌رود:

1. **شفاف‌سازی** — قبل از شروع، سوالات دقیق پرسیده می‌شود تا ابهام به صفر برسد
2. **توافق** — تصمیم‌ها + معیار «تمام‌شده» (Definition of Done) ثبت می‌شود
3. **اجرا** — پیاده‌سازی همراه با اعتبارسنجی خودکار هرجا که ممکن است
4. **بازبینی** — مرور خروجی، درس‌ها و اصلاح مسیر برای گام بعد

**اصل کلی:** مثل یک مهندس نرم‌افزار — مستندسازی سبک اما کافی، تصمیم‌ها با دلیل، و هر فاز فقط وقتی تمام شده که معیار خروجش پاس شود.

## فاز جاری — ۵: راه‌اندازی اسکلت پروژه (تحویل شد ✅)

**تحویل‌شدنی‌ها (ریشه ریپو `music-school-admin/`):**
- Next.js 16 (App Router) + TypeScript strict + Tailwind 4 + shadcn/ui (radix-nova، RTL) + فونت وزیرمتن (لوکال)
- Prisma 6 + PostgreSQL — مایگریشن `init` شامل قیود دستی (ایندکس یکتای جزئی ترم فعال + pg_trgm)
- Seed idempotent: تنظیمات + ۶ ساز + ۳ اتاق + ترم فعال + ادمین اولیه (از env)
- ساختار لایه‌بندی‌شده: `services/` → `repositories/` → `lib/db.ts` (با README قواعد هر لایه)
- صفحه وضعیت فارسی/RTL که زنجیره کامل Next → Service → Repository → Prisma → PG را نشان می‌دهد
- CI: GitHub Actions (مایگریشن روی PG تمیز + lint + typecheck + build)
- `.env.example` + README کامل راه‌اندازی + مستندات و آرتیفکت‌های طراحی در `docs/`

**وضعیت:** ✅ typecheck و build سبز · مایگریشن و seed اعمال‌شده · آماده فاز ۶
