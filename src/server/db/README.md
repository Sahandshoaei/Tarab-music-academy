# server/db — زیرساخت دیتابیس (فراتر از کلاینت)

کلاینت Prisma در `src/lib/prisma.ts` است (تک منبع حقیقت).

این پوشه برای ابزارهای دیتابیسِ سطح بالاتر است که در فاز ۶ اضافه می‌شوند:
- `withTransaction` — wrapper تراکنش برای عملیات چندمرحله‌ای (مثل ثبت کلاس + جلسات)
- کوئری‌های خام SQL (مثل تشخیص تداخل با EXCLUDE) در صورت نیاز به بهینه‌سازی
