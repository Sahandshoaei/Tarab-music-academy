# Permissions — مجوزها (RBAC)

خانه منطق دسترسی و نقش‌ها (آینده‌محور — طبق تصمیم D4 فاز ۳، نقش‌ها از الان در دیتابیس هستند).

**وضعیت فعلی (MVP-1):** فقط ادمین — چک نقش در `server/auth/index.ts` (authorize) و محافظت مسیر در `middleware.ts`.

**فازهای بعد:** توابع `can(user, "attendance:write")` و نقش‌های TEACHER/STUDENT اینجا تعریف می‌شوند — بدون دست‌زدن به کد احراز هویت.
